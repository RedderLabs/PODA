# Código de conducta

Poda adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todo el mundo con respeto, acepta las críticas constructivas, céntrate en lo que es mejor para la gente que usa Poda y no toleres el acoso de ningún tipo. Esto vale en las issues, las discusiones, los PR y cualquier otro espacio del proyecto.

Para informar de un comportamiento inaceptable, escribe a los responsables del proyecto mediante un [aviso privado de seguridad](https://github.com/RedderLabs/PODA/security/advisories/new) indicando que es un asunto de conducta. Se tratará con discreción.
